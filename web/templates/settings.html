Virenscan

{% set eng = conf.get('CLAM_ENGINE', 'auto') or 'auto' %} {% set via_clamd = eng == 'auto' and conf._engine == 'clamd' %}
Vom Virenscan ausnehmen
So richtest du „Antivirus for files“ in Nextcloud ein
  1. Auf dem Server den ClamAV-Dienst installieren: sudo apt install clamav-daemon
  2. In Nextcloud als Administrator: Apps → Sicherheit → „Antivirus for files“ aktivieren.
  3. Verwaltung → Sicherheit → Antivirus: Modus „ClamAV Daemon (Unix Socket)“, Socket /var/run/clamav/clamd.ctl, Aktion bei infizierten Dateien „Datei löschen“ oder „Nur protokollieren“.
  4. Testen: die Testdatei von eicar.org hochladen – Nextcloud muss sie ablehnen.
  5. Danach hier „Nextcloud-Datenordner“ ankreuzen.
